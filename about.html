About the developer.

I'm Vishu. I build websites people enjoy using and Discord bots that keep communities running smoothly.

I start every project by understanding what it needs to do and who will use it. Then I build a structure that stays readable as it grows, so changes later don't feel like a rewrite.

Small details matter to me: spacing, motion, load time and how a bot responds in a busy channel. These are the things people notice even if they can't name them.

Most of my bot work is built with Discord.js v14. My websites are built with clean HTML, CSS and JavaScript, and I add a backend when a project needs one.
